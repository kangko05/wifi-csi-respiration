# B0: Q15 FFT 구현 및 ESP32-C5 실측 — 2026-09-22

## 결과

**FFT 커널은 약 5.5~6배 빨라졌으나, 전체 분석은 37.223 → 29.174초로
약 21.6% 단축됐다. 현재 3초 목표는 달성하지 못했다.**

이 실험은 [실시간화 계획](rx-amplitude-realtime-plan-20260921.md)의 B0만
수행했다. 정수 FIR·슬라이딩 전처리·스펙트럼 통합·연속 분석 태스크 분리는
하지 않았다. 윈도우 60초, 117개 칸, 출력률 10 Hz, PSD oversampling=4를
유지하고 FFT만 Q15로 교체했다. FIR은 비교 양쪽 모두 float다.

## 구현

- `src/csi_utils.c`, `include/csi_resp/csi_utils.h`: Q15 radix-2 FFT,
  계획 생성, float 입출력 변환 어댑터 추가. 기존 FFT 함수는 유지한다.
- 각 FFT 단계에서 정수 배열의 크기를 확인하고 필요할 때만 2의 거듭제곱으로
  축소한다. 매 단계 무조건 반으로 줄이는 방식보다 작은 값의 손실을 줄인다.
  축소 횟수를 반환해 출력 크기를 복원한다. 부호에 대칭인 반올림을 사용한다.
- twiddle은 int16. 계획 최대 4096점일 때 8192 bytes이며 부팅/실험 설정 때
  생성한다. FFT 커널 안에는 실수 연산이 없다.
- `csi_fft_q15_float`는 최대값 검사 → 정수 변환 → 정수 FFT → 실수 복원을
  한다. 역변환은 정규화까지 복원한다. 파이프라인 시간에는 이 비용이 포함된다.
- `csi_amp_raw_source_t.q15_plan`이 NULL이면 기존 경로다. Q15 경로에서만
  2×FFT 용량의 int16 작업 버퍼를 한 번 할당하고 칸마다 재사용한다
  (4096점이면 16384 bytes). 이 버퍼는 일반 malloc이므로 내부 RAM 배치를
  보장하지 않는다. 실제 위치는 이번에 별도 계측하지 않았다.
- PSD 파워·ACF 파워 및 정규화·Hann·추세 제거·점수 계산은 기존 실수 처리다.
- RX Kconfig의 `CSI_RX_AMP_Q15_BENCHMARK`는 벤치마크 모드에 종속된다.
  일반 RX에는 Q15를 기본 적용하지 않는다. 로그는 `csi_output.c/.h`에 유지한다.

## 직접 측정 조건

사용자가 TX/RX 연결과 RX `/dev/ttyUSB0`를 확인한 후 플래시했다.
ESP-IDF v6.0.3, -O2, 240 MHz, PSRAM 40 MHz. 약 60초 입력 수집 후 CSI 수신을
끄고 같은 5991개 레코드(fingerprint `f49c6893`)로 아래 순서로 실행했다.

1. FFT 단독 커널 측정(내부 RAM 작업 배열, 합성 입력).
2. 실제 녹화 윈도우 float → Q15 → Q15 반복 → float 반복.

실제 수신을 계속하면서 3초마다 결과를 보내는 실험은 아니다.
benchmark 종료 후에는 CSI 수신이 비활성화되므로 일반 모드로 복귀한다.

### FFT 단독 커널

배열 생성/채우기와 yield는 측정에서 제외한다. 각 조건 4회 실행한 합계를
4로 나눈 값이다. float와 Q15 작업 배열은 모두 내부 RAM에 명시 할당했다.
float twiddle은 기존 PSRAM double 표, Q15 twiddle은 내부 RAM int16 표다.
따라서 표현 방식과 twiddle 배치 차이가 함께 포함된 비교다.

| 길이·방향 | float 1회 | Q15 1회 | 배속 |
| --- | ---: | ---: | ---: |
| 2048 순방향 | 29.400 ms | 5.249 ms | 5.60배 |
| 2048 역방향 | 31.810 ms | 5.282 ms | 6.02배 |
| 4096 순방향 | 62.715 ms | 11.380 ms | 5.51배 |
| 4096 역방향 | 67.337 ms | 11.449 ms | 5.88배 |

Q15 커널은 축소 횟수를 반환한다. 표의 Q15 역방향 시간에는 float로의
정규화 복원 비용이 없으며 아래 전체 파이프라인 측정에는 포함된다.
4096점 순방향 전체 커널 시간을 butterfly 수로 나누면 약 111 cycles다.
이는 bit reversal·최대값 검사·축소도 포함한 값이다. 계획서의 25~40 cycles는
이번 구현에서 확인되지 않았다.

### 전체 분석

| 항목 | float | Q15 | Q15 반복 | float 반복 |
| --- | ---: | ---: | ---: | ---: |
| 분석 함수 경과 시간 | 37.223초 | 29.174초 | 29.194초 | 37.227초 |
| 설정·보고 포함 총시간 | 37.337초 | 29.279초 | 29.299초 | 37.336초 |

첫 float와 마지막 float의 전체 결과는 byte 단위로 일치했다.
Q15는 양쪽 반복에서 표시된 후보가 동일했고 모든 호출이 status=0이었다.
Q15 반복 간 전체 결과 byte 비교는 보드에서 따로 수행하지 않았다.

| 단계 | float | Q15 |
| --- | ---: | ---: |
| eligibility | 2.482초 | 2.483초 |
| interpolate | 9.822초 | 9.836초 |
| FIR | 6.499초 | 6.495초 |
| detrend | 0.773초 | 0.773초 |
| PSD | 8.712초 | 4.675초 |
| ACF | 7.646초 | 3.375초 |

PSD+ACF는 16.358 → 8.050초, 약 50.8% 감소했다. 커널의 5~6배 개선이
전체 단계에 그대로 적용되지 않는 것은 변환/복원과 남아 있는 실수 계산,
작업 버퍼 접근 등의 비용이 포함되기 때문이다. 이 비용들의 개별 시간은
이번에 분리 계측하지 않았다. 보간·FIR·유효성 검사는 합쳐 약 18.8초로
그대로다. 그래서 **B0만으로 전체 3초가 되는 것은 아니다.**

이 보드 입력에서는 양쪽 모두 withheld, 후보 bin=66, PSD 3.076 bpm이었다.
ACF는 float 47.296 → Q15 47.302 bpm, 표시 score=0.0956, reasons=0xb8.
숫자가 비슷하다는 것이 실제 호흡 검증을 뜻하지 않는다.

## 호스트 수치 검증

루트 테스트 **30개 통과**. Q15용 5개 테스트를 추가했다.

- NumPy FFT/IFFT와 길이 1~4096, 입력 크기 1e-20/1/1e20 비교:
  상대 L2 오차 <0.003을 만족.
- 0·상수·임펄스·단일 주기·약한 추가 주기: 순방향 상대 오차 <0.004,
  왕복 상대 오차 <0.008을 만족. 약한 성분 하나하나의 보존을 보장하는 기준은 아니다.
- int16 최대 범위 입력, 잘못된 인자, 비유한 입력, 합성 진폭 파이프라인 검사.
- 전체 int16 범위 난수의 FFT/역FFT를 길이 1~4096에서 650회 실행한
  UBSan 검사에서 오류가 없었다.
- 초기 FFT 테스트의 큰 입력 비교에서 테스트 자체의 float32 norm이
  overflow했다. 비교 norm을 complex128로 수정한 뒤 통과했다.
  최초 실패 로그도 보존했다.

녹화 21개의 처음 60초를 double/float/Q15로 각각 처리했다. 다음은 float 대비다.

- 최종 채택/보류: 21개 전부 동일(채택 5개).
- 최고 점수 칸·선택된 칸·개별 칸 채택 여부: 전부 동일.
- 최종 후보 PSD bpm: 전부 동일. 최종 후보 ACF 차이 최대 약 0.005306 bpm.
- 모든 칸 중 최대 score 차이: 약 0.006686.
- **일부 선택되지 않은 칸의 피크는 크게 변경**: PSD 최대 34.424 bpm,
  ACF 최대 31.231 bpm 차이. 전체 칸의 수치가 동등하다는 주장은 하지 않는다.

현재 데이터의 최종 판정은 유지됐으므로 B0에서는 Q31까지 확대하지 않았다.
다른 조건의 약한 신호나 임계값 근처 판정에서는 Q15 영향이 달라질 수 있다.
이 결과는 기존 경로 대비 회귀 검증이며 독립적인 호흡 정확도 평가는 아니다.

## 다음 판단

고정소수점 FFT의 속도 향상은 실제로 확인했다. 다만 계획서의 전체
0.6~1.3초 예상은 검증되지 않았으며 이번 결과로 보장할 수 없다.
추가 진행 시 정수 상태 유지에 따른 변환 비용 제거, Hann/파워/점수 계산,
정수 FIR와 증분 전처리를 별도로 측정해야 한다. A/B/C 전체 변경은
이번 B0 범위에 포함하지 않았다. 목표는 분석과 외부 결과 전송을 합쳐
3초이며, 결과 전송 자체는 아직 미구현이다.
